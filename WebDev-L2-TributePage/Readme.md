# Tribute Page

## Task
Oasis Infobyte - Web Development Level 2 - Task 2

## Project Description
This project is a responsive tribute page created using HTML and CSS.

The page presents information about the selected person, including their biography, achievements, image, and a notable quote.

## Features
- Subject name and tagline
- Prominent image
- Biography section
- Key achievements/timeline
- Quote section
- Multiple background sections
- Different font styles
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html` - Tribute page structure
- `style.css` - Page styling
- `script.js` - JavaScript functionality
- `image.png` - Project image

## How to Run
Open `index.html` in a modern web browser.
