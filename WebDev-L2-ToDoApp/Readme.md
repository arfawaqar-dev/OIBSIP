# To-Do Web App

## Task
Oasis Infobyte - Web Development Level 2 - Task 3

## Project Description
This project is an interactive To-Do Web Application developed using HTML, CSS, and JavaScript.

It allows users to add, complete, edit, and delete tasks.

## Features
- Add new tasks
- Pending tasks list
- Completed tasks list
- Mark tasks as complete
- Edit tasks
- Delete tasks
- Pending task count
- Completed task count
- Empty state messages

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html` - Application structure
- `style.css` - Application styling
- `script.js` - To-Do functionality

## How to Run
Open `index.html` in a modern web browser.
