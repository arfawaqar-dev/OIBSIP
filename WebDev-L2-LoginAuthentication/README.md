# Login Authentication System

## Task
Oasis Infobyte - Web Development Level 2 - Task 4

## Project Description
This project is a client-side login authentication system developed using HTML, CSS, and JavaScript.

It provides user registration, login validation, a protected dashboard, and logout functionality.

## Features
- User registration
- Username/email and password validation
- Password validation
- Duplicate user checking
- Login authentication
- Incorrect credential handling
- Protected dashboard
- Logout functionality
- Form validation
- Local storage based session handling

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html` - Login page
- `register.html` - Registration page
- `dashboard.html` - Protected dashboard
- `style.css` - Styling
- `script.js` - Authentication functionality

## How to Run
Open `index.html` in a modern web browser.
