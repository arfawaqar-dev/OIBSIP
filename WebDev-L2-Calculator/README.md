# Scientific Calculator

## Task
Oasis Infobyte - Web Development Level 2 - Task 1

## Project Description
This project is a fully functional web-based Scientific Calculator developed using HTML, CSS, and JavaScript.

It provides basic arithmetic operations along with scientific mathematical functions through an interactive and user-friendly interface.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Percentage calculation
- Scientific mathematical functions
- Clear button
- Backspace/Delete functionality
- Error handling
- Interactive calculator display
- Responsive user interface
- Button-based input
- JavaScript event handling

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html` - Structure of the calculator
- `style.css` - Styling and responsive layout
- `script.js` - Calculator logic and functionality

## How to Run
1. Download or clone the project.
2. Open `index.html` in a web browser.
3. Use the calculator buttons to perform calculations.
